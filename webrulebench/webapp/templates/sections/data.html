Kullanım

  1. + Yeni site (admin): URL, ad ve ülke girin. Ana sayfa indirilir ve site sites.json'a seçilen ülkenin altına eklenir.
  2. ✏️ (admin): sitenin adını, ülkesini ve notunu düzeltin. Domain değiştirilemez — sayfa klasörü ve GT dosyaları ona bağlıdır.
  3. Aç: siteyi annotation ekranında açar. Bir sayfa seçince sağ panelde Yeni Sayfa Ekle ve Sayfayı yeniden indir araçları bulunur (admin).
  4. ⚡ Toplu ekle (admin): bir listing sayfasından CSS selector ile linkler çıkarılır, bulunan sayfalar sırayla indirilir.

Ülke

  • Ülke listeden seçilir; listede yoksa + Yeni ülke… ile İngilizce adı, ISO 3166 kodu (TR, FR…), kıtası ve dili girilir.
  • Bilgisi eksik siteler için ülke, domain uzantısından önerilir (.fr → France); kaydetmeden önce kontrol edin. .com gibi genel uzantılarda öneri yapılmaz.
  • Ülke filtresindeki Bilgisi eksik, sites.json'da kaydı olmayan siteleri gösterir.

Genel bilgi

  • Sayfalar önce requests ile, başarısız olursa Playwright ile indirilir ve dataset/raw/<domain>/{article|listing}_NNN.html olarak kaydedilir.
  • Bir sayfa yeniden indirilince içeriği değiştiği için o sayfanın layout ataması GT'den silinir.
  • Ekleme, düzenleme ve silme işlemleri dataset/deletion_audit.log dosyasına yazılır.
  • Durum noktaları: GT aktarıldı · hazır (≥5 atanmış sayfa) · kısmi · başlanmadı.

Usage

  1. + New site (admin): enter the URL, name and country. The homepage is downloaded and the site is added to sites.json under the selected country.
  2. ✏️ (admin): correct the site's name, country and note. The domain cannot be changed — the page folder and the GT files depend on it.
  3. Open: opens the site in the annotation screen. When a page is selected, the right panel offers the Add new page and Re-download page tools (admin).
  4. ⚡ Bulk add (admin): links are extracted from a listing page with a CSS selector and the pages found are downloaded one by one.

Country

  • The country is selected from the list; if it is not listed, use + New country… and enter its English name, ISO 3166 code (TR, FR…), continent and language.
  • For sites with missing info, a country is suggested from the domain extension (.fr → France); check it before saving. No suggestion is made for generic extensions such as .com.
  • Missing info in the country filter shows the sites that have no record in sites.json.

General information

  • Pages are downloaded with requests first, then with Playwright if that fails, and saved as dataset/raw/<domain>/{article|listing}_NNN.html.
  • When a page is re-downloaded its content changes, so the page's layout assignment is removed from the GT.
  • Add, edit and delete operations are written to dataset/deletion_audit.log.
  • Status dots: GT exported · ready (≥5 assigned pages) · partial · not started.
