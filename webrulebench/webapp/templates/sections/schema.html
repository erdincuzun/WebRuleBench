Kullanım

  1. Bir şablona tıklayın: alanları düzenleme sayfası açılır (düzenleme yalnızca admin; diğer kullanıcılar görüntüler).
  2. 💬 Prompt: şablonun otomatik prompt'unu görün, deneme prompt'ları ekleyin.
  3. + Yeni şablon (admin): kısa bir id verin, ardından alanlarını tanımlayın.

Şablon nedir?

Bir sayfa tipinden hangi alanların çıkarılacağını tanımlar (layout_templates.json). Her layout bir şablondan türetilir. Alan başına: tip (text, date, image, url, list, price), metrik (rouge, jaccard, exact_match, f1), zorunlu ve merge.

Prompt'lar

Prompt sütunundaki 1 + N: bir otomatik prompt + N eklenmiş deneme prompt'u. Otomatik prompt şablonun alanlarından üretilir ve değiştirilemez; deneme prompt'ları template_prompts.json'da tutulur.

Usage

  1. Click a template to open its field editor (editing is admin-only; other users can view).
  2. 💬 Prompt: view the template's automatic prompt and add prompt variants.
  3. + New template (admin): give a short id, then define its fields.

What is a template?

It defines which fields are extracted from a page type (layout_templates.json). Every layout is derived from a template. Per field: type (text, date, image, url, list, price), metric (rouge, jaccard, exact_match, f1), required and merge.

Prompts

1 + N in the Prompt column: one automatic prompt + N added prompt variants. The automatic prompt is generated from the template's fields and cannot be changed; prompt variants are stored in template_prompts.json.
