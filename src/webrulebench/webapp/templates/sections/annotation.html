Kullanım

  1. Listeden bir siteye tıklayın; annotation ekranı açılır.
  2. Sağ panelde layout'u seçin ya da + New Layout ile oluşturun (admin), şablonunu seçin.
  3. Sol panelden sayfa seçin, alanlar için 🎯 ile sayfada element seçin veya kuralı elle yazın; Test ile doğrulayın.
  4. Sayfayı layout'a atayın (Assign Layout). Aynı layout'a ait çok sayfa için ⚡ Toplu atama kullanın.

İki sekme

Kendi Annotation'ım: her annotatörün bağımsız CSS seçimleri — derleme ve Fleiss κ bunlardan hesaplanır. Ground Truth (admin): onaylı kurallar; burada CSS'e ek olarak XPath ve Regex de tanımlanır.

Kural dilleri

CSS selector
Ana kural dili. Sayfada 🎯 ile tıklayarak üretilir ya da elle yazılır; BeautifulSoup select() ile test edilir. Virgülle alternatif verilebilir: merge kapalıysa ilk eşleşen, açıksa hepsi kullanılır.
XPath GT sekmesi
🎯 ile seçilen elemandan CSS ile birlikte otomatik yazılır ya da CSS'ten önerilir (↻); lxml ile test edilir ve sonuç CSS ile karşılaştırılır. Alternatifler | ile birleştirilir.
Regex
Ham HTML metni üzerinde çalışır ve tek yakalama grubu içermelidir. Elle yazılır ya da ↻ ile alanın CSS'inden üretilir: REGEXN yaklaşımının (Uzun, 2020) genişletilmiş hali. Üretilen kalıp layout'un sayfalarında CSS ile karşılaştırılır ve "6/6 sayfada aynı" gibi bir doğrulama sonucu gösterilir. Pseudo-class (:nth-child, :first-child) içeren seçiciler desteklenmez.

↻ yalnızca destek amaçlıdır: üretilen regex bir öneridir, düzenleyip kaydetmek kullanıcıya aittir. Üretim şu makaledeki yaklaşımın genişletilmiş halidir:
Uzun, E. (2020). A regular expression generator based on CSS selectors for efficient extraction from HTML pages. Turkish Journal of Electrical Engineering & Computer Sciences, 28(6), 3389–3401. doi:10.3906/elk-2004-67

Usage

  1. Click a site in the list to open the annotation screen.
  2. In the right panel choose a layout or create one with + New Layout (admin), and choose its template.
  3. Choose a page in the left panel, then pick an element on the page with 🎯 for each field or write the rule by hand; check it with Test.
  4. Assign the page to the layout (Assign Layout). For many pages of the same layout use ⚡ Bulk assign.

Two tabs

My annotation: each annotator's independent CSS rules — compilation and Fleiss κ are computed from these. Ground Truth (admin): the approved rules; here XPath and Regex are defined in addition to CSS.

Rule languages

CSS selector
The main rule language. Generated by clicking on the page with 🎯 or written by hand; tested with BeautifulSoup select(). Alternatives can be separated by commas: if merge is off the first match is used, if it is on all of them are used.
XPath GT tab
Written automatically together with the CSS from the element picked with 🎯, or suggested from the CSS (↻); tested with lxml and the result is compared with the CSS. Alternatives are combined with |.
Regex
Runs on the raw HTML text and must contain a single capturing group. Written by hand or generated with ↻ from the field's CSS: an extended version of the REGEXN approach (Uzun, 2020). The generated pattern is compared with the CSS on the layout's pages and a check result such as "same on 6/6 pages" is shown. Selectors with pseudo-classes (:nth-child, :first-child) are not supported.

↻ is only an aid: the generated regex is a suggestion; editing and saving it is up to the user. The generator is an extended version of the approach in this paper:
Uzun, E. (2020). A regular expression generator based on CSS selectors for efficient extraction from HTML pages. Turkish Journal of Electrical Engineering & Computer Sciences, 28(6), 3389–3401. doi:10.3906/elk-2004-67
