Nasıl çalışır?

Seçilen her model × kural dili bir deneydir. Tek yapılandırma seçilirse tek bir deney, birden çok seçilirse bir karşılaştırma grubu oluşur; grup üyeleri sırayla çalışır (yerel modeller aynı anda yüklenmesin diye). Her deneyde layout başına bir örnek sayfa LLM'e gönderilir, kurallar layout'un tüm GT sayfalarında skorlanır.

Alanlar

  • Modeller: ⚙ LLM Modelleri sayfasındaki backend + model çiftleri. Anahtarı olmayan bulut modeli hata verir.
  • Kural dilleri: CSS, XPath, Regex; CSS→REGEXN LLM'in CSS ürettiği, regex'e REGEXN ile (yalnızca örnek sayfa kullanılarak) çevrildiği koşuldur. Skorlama her zaman GT içeriğiyle yapılır.
  • HTML temizleme: whitelist (önerilen) ya da raw_regex.
  • Prompt: seçilen kural dilleri aynı prompt diline düşüyorsa (ör. yalnızca CSS ya da CSS + CSS→REGEXN) şablon başına deneme prompt'u seçilebilir; aksi halde her kural dili kendi otomatik prompt'unu kullanır. 👁 ile LLM'e gidecek metni görün.
  • Örnek sayfa: rastgele seçimde seed kaydedilir; aynı seed aynı sayfaları seçer. En fazla sayfa yalnızca skorlama süresini kısaltır.

How does it work?

Each selected model × rule language is one experiment. If a single configuration is selected one experiment is created; if several are selected a comparison group is created, whose members run one after another (so that local models are not loaded at the same time). In each experiment one sample page per layout is sent to the LLM and the rules are scored on all GT pages of the layout.

Fields

  • Models: backend + model pairs from the ⚙ LLM Models page. A cloud model without a key fails.
  • Rule languages: CSS, XPath, Regex; CSS→REGEXN is the condition where the LLM generates CSS that is converted to regex with REGEXN (using only the sample page). Scoring is always done against the GT content.
  • HTML cleaning: whitelist (recommended) or raw_regex.
  • Prompt: if the selected rule languages map to the same prompt language (e.g. only CSS, or CSS + CSS→REGEXN), a prompt variant can be chosen per template; otherwise each rule language uses its own automatic prompt. Use 👁 to see the text that will be sent to the LLM.
  • Sample page: for random selection the seed is saved; the same seed selects the same pages. Max pages only shortens scoring time.
