Kullanım

  1. Ad, açıklama ve sayfa tipini düzenleyin; açıklama otomatik prompt'ta sayfa tanımı olarak kullanılır.
  2. + Alan ekle ile alan ekleyin; ↑ ↓ ile sıralayın, ✕ ile silin.
  3. 💾 Kaydet ya da Kaydet ve listeye dön. Kaydetmeden sayfadan çıkarsanız uyarı alırsınız.

Alan sütunları

  • Açıklama — otomatik prompt'un ana girdisi: ne kadar net olursa üretilen prompt o kadar iyi olur.
  • Tip — text, date, price, url, image, list.
  • Metrik — değerlendirmede kullanılır: rouge (ROUGE-1 F1), jaccard (küme benzerliği), exact_match, f1.
  • Zorunlu — alan sayfada mutlaka bulunmalı.
  • Merge — CSS'te virgülle ayrılmış alternatiflerin hepsi uygulanıp birleştirilir; kapalıysa ilk eşleşen kullanılır.

Dikkat

Alan silmek veya adını değiştirmek bu şablonu kullanan layout'ların mevcut kurallarını etkileyebilir.

Usage

  1. Edit the name, description and page type; the description is used as the page definition in the automatic prompt.
  2. Add fields with + Add field; reorder them with ↑ ↓ and delete them with ✕.
  3. 💾 Save or Save and return to list. If you leave the page without saving, you will get a warning.

Field columns

  • Description — the main input of the automatic prompt: the clearer it is, the better the generated prompt.
  • Type — text, date, price, url, image, list.
  • Metric — used in evaluation: rouge (ROUGE-1 F1), jaccard (set similarity), exact_match, f1.
  • Required — the field must be present on the page.
  • Merge — in CSS, all comma-separated alternatives are applied and merged; if off, the first match is used.

Caution

Deleting or renaming a field may affect the existing rules of layouts that use this template.
