Otomatik prompt

Bilerek sadedir: yalnızca görevi, bulunacak alanları (şablondaki açıklamalarıyla) ve JSON çıktı biçimini söyler. Şablon değişince kendiliğinden güncellenir. Daha ayrıntılı kurallar denemek için kopyalayıp genişletin (örnek: Ayrıntılı kurallar prompt'ları).

Sistem ve kullanıcı prompt'u

Sistem prompt'u görevi ve kuralları tanımlar. Kullanıcı prompt'u her sayfa için gönderilir ve {skeleton} (zorunlu) ile {domain} yer tutucularını içerir; düz süslü parantez için {{ '{{ }}' }} yazın.

Usage

  1. ⚙ Automatic prompt: choose the rule language (css / xpath / regex) and view the prompt generated from the template — it is read-only.
  2. 📋 Copy → new prompt or + New prompt: start from the automatic prompt, edit it, give it a name and click Create.
  3. Select an added prompt to edit it, derive a variant with Duplicate, or delete it.

Automatic prompt

It is deliberately plain: it only states the task, the fields to find (with their descriptions from the template) and the JSON output format. It updates itself when the template changes. To try more detailed rules, copy it and extend it (example: the Detailed rules prompts).

System and user prompt

The system prompt defines the task and the rules. The user prompt is sent for every page and contains the {skeleton} (required) and {domain} placeholders; for a literal curly brace write {{ '{{ }}' }}.

Sharing

Everyone can see added prompts; only the owner or an admin can change or delete them. No versions are kept — saving overwrites.
