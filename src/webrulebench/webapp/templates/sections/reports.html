LLM sonuçlarının tanımı

  • Ortalama: layout ortalamalarının ortalaması (makro). Layout ortalaması: o layout'un bütün GT sayfaları × alanlarının skoru (ROUGE / Jaccard / EM, şablondaki alan metriği).
  • Örnek: LLM'in gördüğü sayfadaki skor; Diğer: geri kalan GT sayfaları (genelleme); Fark = Örnek − Diğer (küçük olması iyi).
  • MATCH: skoru ≥ 0.9 olan (sayfa, alan) hücrelerinin oranı.
  • Ortak layout kümesi açıkken yalnızca seçili deneylerin hepsinde başarıyla çalışmış layout'lar hesaba katılır — farklı kapsamdaki deneyler adil karşılaştırılır.

Tabs

  • 📦 Dataset — distribution of sites, pages and layouts by country / language / continent; templates, field coverage (share of layouts with a GT rule), distribution of pages per layout.
  • ✍ Annotation & GT — user progress; GT status per rule language (approved / has updates / none); Fleiss κ per field and low-agreement layouts; on request, content-level agreement (Krippendorff α on the values the rules extract from all GT pages), annotator pairs and agreement per layout.
  • 🤖 LLM results — a single leaderboard across all experiments; score–cost chart; breakdown by field, country, language, continent, template or site; cross-check groups.
  • ⬇ Export — GT dataset (JSONL / CSV / HuggingFace), dataset card (README.md), reproducibility manifest.
  • 🧾 Audit log (admin) — add, delete, compile, experiment and user actions.

Output for papers

  • Every table has CSV, LaTeX (booktabs; the best value in each column in bold) and MD buttons at the top. Click a column header to sort; the export uses the same order.
  • Every chart has PNG (white background, 2× resolution, color-blind-safe palette) and CSV (the chart's data — for redrawing with matplotlib etc.) at the top.

Definition of the LLM results

  • Mean: the mean of the layout means (macro). Layout mean: the score over all GT pages × fields of that layout (ROUGE / Jaccard / EM, the field metric in the template).
  • Sample: the score on the page the LLM saw; Others: the remaining GT pages (generalization); Gap = Sample − Others (smaller is better).
  • MATCH: the share of (page, field) cells with a score ≥ 0.9.
  • With Common layout set on, only layouts that ran successfully in all selected experiments are counted — experiments with different scopes are compared fairly.
